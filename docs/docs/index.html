Build & Run

TDSE-ⵣ is a C++17 framework built on PETSc/SLEPc with IGA B-spline discretization. Clone, compile, and launch your first simulation in under a minute.

1. Clone & Build

TDSE-ⵣ requires PETSc (with or without CUDA) and SLEPc. The build system uses CMake. After cloning, configure and compile with the commands below.

bash — TDSEZ 
$ git clone https://github.com/dahbiz/tdsez.git
$ cd TDSEZ
$ cmake -B build # -DPETSC_DIR=... -DSLEPC_DIR=... if not in PATH
$ cmake --build build -j$(nproc)
$  # → produces build/tdsez

2. Run a Simulation

Each simulation is driven by a plain-text input file (.inp) declaring the domain, potential, laser field, and propagation parameters. Run the solver in serial or parallel with MPI.

bash — TDSEZ/build 
$ ./tdsez -inp examples/model.inp
$ mpirun -np 4 ./tdsez -inp examples/model.inp
$  # GPU mode (PETSc built with --with-cuda=1):
$ mpirun -np 4 ./tdsez -inp examples/model.inp \
    -vec_type cuda -mat_type aijcusparse
$  # Eigenvalues only (no propagation):
$ ./tdsez -inp examples/model.inp -ts_max_steps 0

3. Input File

A minimal 1D soft-Coulomb atom driven by a 3-cycle 800 nm pulse. Two lines of potential, one line of laser — that's all TDSE-ⵣ needs to run.

examples/model.inp 
# Domain and basis
Dimension    = 1
LMin         = -120.0
LMax         =  120.0
NSplines     = 600
SplineDegree = 5

# 1D soft-Coulomb atom
Mass         = 1.0
Potential    = -1.0 / sqrt(x^2 + 1.0)

# 3-cycle 800 nm pulse
Ampx        = 0.05
Omegax      = 0.056954
LaserX      = Ampx*cos(Omegax*t)*sin(pi*t/331.0)^2

# Time propagation
TimeStep    = 0.05
FinalTime   = 331.0

4. MPI Notes

With OpenMPI 5.x, mpirun -np 1 defaults to --bind-to core, pinning the process to a single physical core. This causes an 8–10× slowdown because PETSc/SLEPc internal BLAS threads compete for one core. Fix it with:

bash 
$ mpirun --bind-to none -np 1 ./tdsez -inp model.inp
$  # or equivalently:
$ mpirun --oversubscribe -np 1 ./tdsez -inp model.inp

5. Common CLI Flags

All flags can be passed on the command line and override input-file values.

bash 
$ ./tdsez -inp file.inp      # specify input file
$ ./tdsez -ts_max_steps 0    # eigenvalues only, no propagation
$ ./tdsez -vec_type cuda      # GPU vectors
$ ./tdsez -mat_type aijcusparse # GPU matrices
$ ./tdsez -use_gpu_aware_mpi 0 # non-GPU-aware MPI workaround
$ ./tdsez -help               # full PETSc options dump
