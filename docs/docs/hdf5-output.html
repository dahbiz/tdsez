Ring Buffer

Output is buffered in a ring buffer of 5000 steps. Flushed every OutputStrideTS steps or every 5000 steps, whichever comes first.

Eigenstate Data

File: static/EigenData_*.h5

Datasets: spectrum (1D, float64), psi_0, psi_1, … (complex vectors), run_metadata group with code_version, input_file, units, grid params, eigenvalue residuals. Each axis dataset (knots_x, knots_y, knots_z) has attributes: mult_start_end (2-int), SplineDegree, nfuncs.
