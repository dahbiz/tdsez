Grid & Domain

TDSE-Z discretises the wave function in a tensor-product B-spline basis [deBoor2001] [Bachau2001] on a rectangular box, using the isogeometric analysis framework PetIGA [Hughes2005] [Dalcin2016]. This page describes the keys that define the box, the basis and the quadrature. The placement of the knots along each axis is described in Knot Sequences; all keys are listed in Input File.

Discretisation

Along each axis \(a\) the basis consists of the \(n_a\) B-splines \(B_{i}^{(a)}\) of degree \(p\) (SplineDegree) on a clamped knot vector (end knots of multiplicity \(p+1\)). In \(d\) dimensions the wave function is expanded as

(7)\[\psi(\mathbf r, t) = \sum_{i_1,\dots,i_d} c_{i_1\dots i_d}(t)\, B^{(1)}_{i_1}(x_1)\cdots B^{(d)}_{i_d}(x_d),\]

so the number of degrees of freedom is \(N_{\mathrm{DOF}} = \prod_a n_a\). With Basis = bspline and simple interior knots,

(8)\[n_a = N_{\mathrm{el}} + p ,\]

where \(N_{\mathrm{el}}\) is the number of elements (knot spans) of the axis. Within an element the basis is polynomial of degree \(p\); across a simple knot it is \(C^{p-1}\).

Dimension and bounds

Key

Type

Default

Description

Dimension

int

1

Spatial dimension, 1, 2 or 3.

Domain

string

–

lo, hi sets every axis; [lox,hix], [loy,hiy], [loz,hiz] sets the axes separately (missing pairs copy the x pair).

LMinX, LMaxX, LMinY, LMaxY, LMinZ, LMaxZ

real

-10, 10

Bounds of each axis (a.u.). They must be finite with LMax > LMin.

OffsetX, OffsetY, OffsetZ

real

0

Translation of the mesh along each axis.

Example of an asymmetric 2D box:

Dimension = 2
Domain    = [-60, 60], [-30, 30]

OffsetX/Y/Z translate the computational box: axis \(a\) spans \([L_{\min,a} + o_a,\ L_{\max,a} + o_a]\). The offsets are added to the bounds once at start-up, so the knots, the potential, mass and dipole operators, the input validation, the CAP layers, the t-SURFF checks and the printed reports all use the shifted box. The hydrogenic sequence is built symmetrically about the origin from \(L_{\max}\) (see Knot Sequences).

Mesh resolution

Key

Type

Default

Description

Nelements (NSplines, NumberOfSplines, ElementCount, NumberOfElements)

int

100

Number of elements per axis (the same value on every axis), at least 1. The hydrogenic and interface sequences set or redistribute the element count themselves (Knot Sequences).

SplineDegree

int

3

Polynomial degree \(p\), 1 to 14.

A warning is printed when the x axis has fewer than \(2p+1\) interior knots (Nelements - 1 < 2 SplineDegree + 1), since such a basis cannot represent localised states reliably.

A higher degree gives a higher convergence order per degree of freedom at the price of wider matrix bands (each row couples \((2p+1)^d\) basis functions).

Basis

Key

Type

Default

Description

Basis (BasisType)

string

bspline

bspline, bernstein, lagrange or spectral (Lagrange polynomials at the Gauss-Lobatto points); case-insensitive.

The element bases bernstein, lagrange and spectral are \(C^0\): after the knot vector of an axis has been generated, every distinct interior knot is raised to multiplicity \(p\), which gives \(n_a = p\,N_{\mathrm{el}} + 1\) functions on an axis with \(N_{\mathrm{el}}\) elements. The three element bases span the same space and differ only in conditioning. Preconditioner = mg requires Basis = bspline, because its prolongation is B-spline knot insertion. A measured comparison is given in Knot Sequences.

Quadrature

Key

Type

Default

Description

NQuadratures

int

8

Quadrature points per element and axis. PetIGA provides Gauss-Legendre rules with 1 to 10 points and Gauss-Lobatto rules with 2 to 10 points.

QuadratureRule (QuadratureType)

string

legendre

legendre (Gauss), lobatto (Gauss-Lobatto, includes the element ends) or reduced (PetIGA’s reduced B-spline rule); case-insensitive.

An \(n_q\)-point Gauss-Legendre rule integrates polynomials up to degree \(2n_q - 1\) exactly. The integrands of the overlap and kinetic matrices for a constant mass have degree \(2p\) and \(2p-2\) per axis, so

(9)\[n_q \ge p + 1\]

integrates them exactly. Position-dependent masses and potentials are not polynomial; singular potentials such as \(1/r\) require a convergence study in \(n_q\) (Knot Sequences). A Gauss-Lobatto rule evaluates the potential at the knots; if it is infinite there the Hamiltonian contains non-finite entries and the run stops after assembly with a message.
