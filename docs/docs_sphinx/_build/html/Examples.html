Examples

The repository contains two sets of input decks: the strong-field examples in examples/, documented with measured results, and the reference decks in tests/inputs/, which the test suite runs against analytic values.

Running a Deck

tdsez.x is built in build/ (Compilation). It writes its output relative to the working directory: static/EigenData_<input>.h5 for the eigenstates and td/TimeEvolutionData_<input>.h5 for the time series, where <input> is the file name of the deck (HDF5 Output Schema). Always launch through mpiexec with --bind-to none (MPI Notes):

mpiexec -n 1 --bind-to none build/tdsez.x -inp tests/inputs/ho1d.inp
mpiexec -n 4 --bind-to none build/tdsez.x -inp tests/inputs/ho2d.inp

Strong-Field Examples (examples/)

Files

Content

examples/hhg/hhg_1d.inp, examples/hhg/hhg_spectrum.py

High-harmonic generation from a 1D soft-core atom (800 nm, \(10^{14}\) W/cm², flat-top pulse); spectrum from the acceleration, the current and the dipole. See Simulating HHG Correctly.

examples/tsurff/free_packet_1d.inp, examples/tsurff/plot_tsurff.py

t-SURFF benchmark: free Gaussian wave packet in a laser pulse against the analytic spectrum. See Photoelectron Spectra (t-SURFF).

examples/tsurff/ati_1d.inp, examples/tsurff/plot_tsurff.py

Above-threshold ionisation spectrum of a 1D soft-core atom with t-SURFF. See Photoelectron Spectra (t-SURFF).

Run these decks from their own directory, as shown on the linked pages, so that the post-processing scripts find td/ next to them.

Reference Decks (tests/inputs/)

Harmonic oscillator

The oscillator decks use \(m = 1\), \(\omega = 0.2\), degree-5 B-splines on uniform knots and no field. In atomic units

(6)\[H = -\frac{1}{2}\nabla^2 + \frac{1}{2}\omega^2 r^2 ,\qquad E = \Big(n_1 + \dots + n_d + \frac{d}{2}\Big)\,\omega ,\]

so the levels of Eq. (6) have the degeneracies 1, 2, 3 in 2D and 1, 3, 6 in 3D.

Soft-core molecules and atoms

Deck

Content

h2p.inp, h2p_2d.inp

Soft-core \(\mathrm{H}_2^+\) model \(V = -1/\sqrt{(x+1)^2+1.44} - 1/\sqrt{(x-1)^2+1.44}\) in 1D (and the same potential, independent of \(y\), in 2D) with a trapezoidal 800 nm pulse; short propagation (\(T = 10\)) through the full eigensolver, propagation and HDF5 output path.

bench_h1d.inp

1D soft-core hydrogen \(V = -1/\sqrt{x^2+1.44}\), 4-cycle sin² vector-potential pulse at 800 nm (\(E_0 = 0.0534\)), 740 a.u. of propagation without CAP.

bench_h3d.inp

The same pulse on the 3D soft-core atom \(-1/\sqrt{r^2+1.44}\) (degree 7, 100 elements per axis); a large run intended for benchmarking on many cores.

Decks that must fail

These decks check the input validation; each run stops with a FATAL or ValidateOrThrow message (Troubleshooting).
