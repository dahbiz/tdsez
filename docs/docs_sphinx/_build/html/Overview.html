TDSE-Z
  • Overview
  • View page source

Overview

Governing equations, discretisation and the solver workflow of TDSE-Z. The class structure is described in Architecture; sign conventions in Physics Conventions.

Model

TDSE-Z treats one particle of charge \(q\) (Charge, default \(-1\)) with a position-dependent mass \(m(\mathbf r)\) (Mass) in a potential \(V(\mathbf r)\) (Potential). The field-free Hamiltonian uses the Hermitian BenDaniel–Duke ordering of the kinetic energy [BenDanielDuke1966],

(1)\[H_0 = -\frac{1}{2}\,\nabla\cdot\frac{1}{m(\mathbf r)}\,\nabla + s\,V(\mathbf r), \qquad s = -q,\]

which reduces to \(-\nabla^2/(2m_0)\) for a constant mass. With EnableCAP = 1 a complex absorbing potential [Manolopoulos2002] is added near the domain boundaries (Boundary Conditions). The laser field \(\mathbf E(t)\) couples in the length gauge,

(2)\[i\,\partial_t\psi(\mathbf r,t) = \bigl[H_0 + s\,\mathbf r\cdot\mathbf E(t)\bigr]\,\psi(\mathbf r,t).\]

Discretisation

The wavefunction is expanded in tensor-product B-splines of degree p [deBoor2001] [Bachau2001], \(\psi(\mathbf r,t) = \sum_j c_j(t) B_j(\mathbf r)\), built and integrated by PetIGA [Dalcin2016]. The Galerkin projection of Eq. (2) gives the semi-discrete system

(3)\[i\,\mathbf M\,\dot{\mathbf c} = \Bigl[\mathbf H + s\sum_{a} E_a(t)\,\mathbf D_a\Bigr]\mathbf c,\]

with the overlap (mass) matrix \(M_{ij} = \langle B_i|B_j\rangle\), the Hamiltonian matrix \(\mathbf H\) of Eq. (1) and the position matrices \((\mathbf D_a)_{ij} = \langle B_i|x_a|B_j\rangle\). The sum runs over the axes in Polarization. For Propagator = cn PETSc TS integrates the residual form

(4)\[\mathbf F = i\,\mathbf M\,\dot{\mathbf c} - \mathbf H\mathbf c - s\sum_a E_a(t)\,\mathbf D_a\,\mathbf c = 0\]

with the theta method at \(\theta = 1/2\) (Crank–Nicolson [Crank1947]). The pade22 and magnus4 propagators apply the Padé(2,2) approximant of the step exponential to Eq. (3), in the second case inside a commutator-free Magnus scheme [BlanesMoan2006] [Alvermann2011]; see Time Propagation.

Bound states solve the generalised eigenproblem

(5)\[\mathbf H\,\mathbf c_n = E_n\,\mathbf M\,\mathbf c_n\]

with SLEPc [Hernandez2005] (shift-invert Krylov–Schur [Stewart2002], see Eigensolver).

Workflow

A run of tdsez.x follows the stages of Fig. 1:

  1. Read and validate the input file (Input File).

  2. Build the knot vectors and the IGA space (Grid & Domain, Knot Sequences).

  3. Assemble \(\mathbf H\) and \(\mathbf M\).

  4. Solve Eq. (5) for NBoundStates states (skipped for NBoundStates = 0 with an analytic or wave-packet initial state) and write static/EigenData_<input>.h5.

  5. Build the initial state (Initial State).

  6. With EnablePropagation = 1 (default): assemble the time-dependent operators, propagate Eq. (3) to FinalTime and record the observables at every step (Observables).

  7. Flush the buffered HDF5 rows and print the timing summary.

Output files

<input> is the file name of the input file (without directories).

File

Content

static/EigenData_<input>.h5

Spectrum, eigenstates (with NBoundStatesSave = 1), knot vectors and run metadata; written when NBoundStates > 0.

static/D{x,y,z}_<input>.bin

Dipole operator matrices in PETSc binary format; written with SaveDipoleMatrix = 1 or -save_dipole.

static/TDMInfo_<input>.txt

Transition dipoles and oscillator strengths between the bound states; written at the start of a propagation run.

static/GS_<input>.log

Degenerate-shell splitting log (2D, EnableLzDiag = 1).

td/TimeEvolutionData_<input>.h5

Time series: dipoles, energies, currents, populations, autocorrelation.

td/wfs_<input>.h5

Wavefunction snapshots every OutputStrideWFS steps.

td/surff_<input>.h5

t-SURFF momentum spectrum (TSurff = 1).

ts_<input>.h5

PETSc TSView output in the working directory (OutputStrideTS > 0).

Dataset layouts are listed in HDF5 Output Schema. The post-processors tdmprocessor, tdmselect and drecprocessor read the static/ files (Post-Processing).
