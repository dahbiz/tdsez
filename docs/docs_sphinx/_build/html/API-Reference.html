API Reference

The public C++ surface is split into focused headers. Include the smallest header that owns the type you use; tdsez_internal.hpp is retained as the compatibility umbrella for solver translation units.

Core lifecycle

The normal lifecycle is:

TDSEZCore core(input_file);
PetscCall(core.Assemble());
PetscCall(core.Solve());
PetscCall(core.Output());

TDSEZAssembler assembler(core.iga);
TDSEZManager manager(&core, &assembler);
TDSEZPropagator propagator(manager);
PetscCall(propagator.Evolve());
PetscCall(manager.CloseHDF5());

Applications must initialize PETSc/SLEPc before constructing these objects and finalize PETSc after all owned objects have been destroyed.

Error handling

Functions returning PetscErrorCode use PETSc error propagation. Callers should use PetscCall inside PETSc-aware functions and PetscCallAbort only at top-level boundaries where there is no recoverable caller. Parser validation throws std::runtime_error before assembly; command-line entry points convert those failures into a clear fatal diagnostic.
