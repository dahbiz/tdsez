API Reference

The C++ declarations live in include/. Solver translation units include the umbrella header tdsez_internal.hpp, which pulls in the parser, assembler, core, manager and propagator headers together with the shared form kernels, callbacks and helper functions.

Table 12 Headers

Header

Main symbols

tdsez_internal.hpp

Umbrella header; residual/Jacobian callbacks (TDSEZIFunctionPol*, TDSEZIJacobianPol*), TDSEZProfile, diagnostics and helper declarations

tdsez_parser.hpp

TDSEZParser: input parameters, muParser expressions, validation

tdsez_core.hpp

TDSEZCore: IGA setup, knot generation, eigensolve, initial state

tdsez_assembler.hpp

TDSEZAssembler: operator matrices

tdsez_manager.hpp

TDSEZManager: propagation operators, observables, HDF5 output

tdsez_propagator.hpp

TDSEZPropagator: time stepping; TDSEZPCRefresh

tdsez_tsurff.hpp

TDSEZTSurff: t-SURFF photoelectron spectra

tdsez_tensorops.hpp

TDSEZTensorOps: factorised application of separable operators

tdsez_quadobs.hpp

TDSEZQuadObs: monitor expectation values at quadrature points

tdsez_multigrid.hpp

TDSEZSetupMultigrid: geometric B-spline multigrid

tdsez_forcecoeffs.hpp

ForceCoeffs, ForceCoeffStore: force-matrix coefficients with mass-gradient corrections, shared by the assembly and the monitors

tdsez_info.hpp

TDSEZInfo: terminal formatting

Lifecycle

The executable (src/tdsez.cpp) uses the classes in this order; the listing omits the optional dipole export and diagnostics.

SlepcInitialize(&argc, &argv, PETSC_NULLPTR, PETSC_NULLPTR);

TDSEZCore core(input_file);          // parse, validate, create the IGA
PetscCall(core.Assemble());          // H and M
PetscCall(core.Solve());             // eigenstates and core.initialPsi
PetscCall(core.Output());            // static/EigenData_<input>.h5

TDSEZAssembler assembler(core.iga);  // time-dependent operators
TDSEZManager manager(&core, &assembler);
manager.setPsi0(psi0);               // copy of core.initialPsi
manager.outputFilename = "td/TimeEvolutionData_<input>.h5";

TDSEZPropagator propagator(manager);
PetscCall(propagator.Evolve());      // evolves core.initialPsi in place
PetscCall(manager.CloseHDF5());

SlepcFinalize();

Output() is called only for NBoundStates > 0, and the propagation block only for EnablePropagation = 1. With TSurff = 1 a TDSEZTSurff object is set up before Evolve(), attached through manager.tsurff and finished afterwards. All objects must be destroyed before SlepcFinalize().

Error handling

Functions returning PetscErrorCode propagate errors through PETSc: PetscCall inside PETSc-aware functions, PetscCallAbort at the top level. Input validation (TDSEZParser::ValidateOrThrow) runs in the TDSEZCore constructor before any PETSc object is created; a failure prints TDSEZ FATAL: input validation failed with the reason and aborts with exit code 3. Other exceptions reaching main() are reported as ERROR: and end the run with exit code 1.
