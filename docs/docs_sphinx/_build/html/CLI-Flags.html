CLI Flags

The physical problem is defined in the input file (Input File). The command line selects the input file, overrides two input keys, and passes TDSE-Z diagnostic switches and PETSc, SLEPc and PetIGA options [PETSc] [Hernandez2005] [Dalcin2016].

Basic usage

$ mpiexec -n 4 ./tdsez.x -inp run.prm
$ ./tdsez.x -inp run.prm -save_dipole xyz
$ ./tdsez.x -inp run.prm -enable_gpu 1
$ ./tdsez.x -help

For a bound-state calculation without propagation set EnablePropagation = 0 in the input file.

Option handling

Input-file keys cannot be set on the command line, with two exceptions: -enable_gpu overrides EnableGPU and -save_dipole overrides SaveDipoleAxes. These two flags and -mat_type/-vec_type are removed from the argument list before PETSc is initialised. All other options go to the PETSc options database and are read by the object that uses them.

Program flags

Flag

Type

Description

-inp <file>

string

Input file (default tdse.prm). Output file names are derived from its base name.

-enable_gpu <0|1>

int

Overrides EnableGPU.

-save_dipole <axes>

string

Overrides SaveDipoleAxes: any combination of x, y, z, all or none. The requested dipole operators are written to static/D<a>_<input>.bin; only assembled operators are written.

-mat_type <type>, -vec_type <type>

string

Matrix and vector types of all PetIGA objects; passed on as -iga_mat_type and -iga_vec_type.

Assembly and eigensolver flags

Flag

Type

Description

-tdsez_sumfact <bool>

bool

Sum-factorised element kernels (default 1); 0 uses the per-point kernels.

-tdsez_sumfact_check

flag

Compute every element matrix both ways and print the largest relative difference (diagnostic, slow).

-tdsez_band <bool>

bool

Banded accumulation of the element matrices with one insertion per matrix row (default 1); 0 inserts element by element.

-tdsez_assembly_buffer_mb <MB>

real

Memory budget per rank for the banded accumulation (default 1024). Larger sets of matrices are assembled in several element passes.

-tdsez_eps_inner <mode>

string

First inner solver of the shift-invert eigensolve: direct or iterative. By default a direct solver is used when a direct package is available and the problem is small enough (1D and 2D up to \(2\cdot 10^6\) rows; 3D with degree \(\ge 6\) and at most \(3\cdot 10^4\) rows), iterative otherwise. A failed attempt falls back to the next solver. See Eigensolver.

-tdsez_degeneracy_tol <tol>

real

Relative energy tolerance for treating eigenvalues as one degenerate level (default 1e-9); see Eigensolver.

The eigensolver also reads the SLEPc options (-eps_*, -st_*, -st_ksp_*, -st_pc_*, -st_sub_*), which apply on top of the settings chosen by TDSE-Z.

Propagation flags

Flag

Type

Description

-tdsez_cap_check

bool

Also assemble the CAP with the element kernel and print the largest difference to the separable assembly (diagnostic).

-tdsez_tensor_ops <bool>

bool

Apply \(M\), the dipoles, the velocities and \(K\) in the monitors in factorised (Kronecker) form (default 1, 2D/3D, not with Dirichlet walls); 0 uses the assembled sparse matrices.

-tdsez_quad_obs <bool>

bool

Evaluate \(\langle V\rangle\), \(\langle 1/m\rangle\), \(\langle K\rangle\), the CAP, the forces \(\partial V/\partial x_a\) and the velocities of the monitors from \(\psi\) at the quadrature points (default 1, 2D/3D, not with Dirichlet walls); 0 uses the assembled matrices.

-tdsez_ilu_levels <n>

int

ILU fill level of the ASM subdomain blocks of the propagator preconditioner (default 0). Level 1 saves at most one GMRES iteration, while its fill makes 3D factorisations about ten times slower.

-pade_guess_order <q>

int

Order of the extrapolated initial guess of the pade22 and magnus4 stage solves, 1 to 5 (default 3).

-pade_extrapolate_guess <bool>

bool

Extrapolated initial guess of the pade22 and magnus4 stage solves (default 1); 0 disables it.

Propagator = cn runs on a PETSc TS and reads the -ts_*, -snes_*, -ksp_* and -pc_* options; -ts_max_steps affects only this propagator. See Time Propagation.

Environment variables

TDSEZ_DUMP_KNOTS

When set, the interior knots of a non-uniform x axis are printed after the knot vector has been generated (Knot Sequences).

Help

-help lists the PETSc, SLEPc and PetIGA options that the run queries.
