Knot Sequences

The knot sequence of an axis fixes the element boundaries of the B-spline basis (Grid & Domain) and therefore where the grid is fine and where it is coarse. TDSE-Z provides uniform, graded, interface-aligned and hydrogenic sequences. This page defines them, describes the field-resolution check that applies to every sequence, and reports convergence studies for Coulomb potentials and high-harmonic generation (HHG).

Selection

KnotSequence takes one name for all axes or a comma-separated list, one name per axis (case-insensitive):

KnotSequence = symexp                 # every axis
KnotSequence = hydrogenic, uniform    # x hydrogenic, y uniform, z uniform (default)
KnotSequence = symexp, uniform, symtanu

A single name applies to every axis; with two names the z axis keeps the default uniform. Valid names are uniform, symexp, symtanu, symtann, symlogtan, hydrogenic and interface (alias interfaces); any other name stops the run during input validation. The knot vectors are generated on rank 0 and broadcast; the environment variable TDSEZ_DUMP_KNOTS prints the interior knots of a non-uniform x axis.

Breakpoints of Potential and Mass

KnotAlpha (aliases KnotGrading, GradingStrength) applies to all graded axes; a value \(\le 0\) selects the defaults listed above. The hydrogenic keys are per-axis lists (Input File).

Graded sequences

symexp, symtanu, symtann and symlogtan place \(n = N_{\mathrm{el}} - 1\) interior knots (Nelements - 1) at the images of the uniform parameters

(10)\[t_i = \frac{2i}{n+1} - 1, \qquad i = 1, \dots, n,\]

under a map of \((-1, 1)\) onto the axis, with \(\alpha\) = KnotAlpha:

(11)\[x_i = L_\pm\,\frac{e^{\alpha |t_i|} - 1}{e^{\alpha} - 1}, \qquad L_+ = L_{\max}\ (t_i \ge 0),\quad L_- = L_{\min}\ (t_i < 0),\]
(12)\[x_i = L_{\min} + (L_{\max} - L_{\min})\, \tfrac12\left[1 + \frac{\operatorname{artanh}(t_i \tanh\alpha)}{\alpha}\right],\]
(13)\[x_i = L_{\min} + (L_{\max} - L_{\min})\, \tfrac12\left[1 + \frac{\tanh(\alpha t_i)}{\tanh\alpha}\right],\]
(14)\[x_i = L_{\max}\,\frac{\tan(\alpha' t_i)}{\tan\alpha'}, \qquad \alpha' = 1.57\,\frac{\alpha}{\alpha + 1}.\]

symexp grades towards \(x = 0\) and scales each side to its own wall, so it also serves boxes that are asymmetric about the origin. symtanu and symtann are symmetric about the box centre. symlogtan uses \(L_{\max}\) for both sides and assumes \(L_{\min} = -L_{\max}\).

A knot lies at \(t = 0\) (the origin, or the box centre) only when \(n\) is odd, i.e. when Nelements is even; otherwise a warning is printed. A Coulomb centre should sit on a knot (see the quadrature study under Coulomb potential: 3D hydrogen).

Hydrogenic sequence

The hydrogenic sequence is built on the half axis \([0, L]\) with \(L = L_{\max}\) and mirrored about the origin; the axis is \([-L_{\max}, L_{\max}]\) and LMin is not used. With \(N_{\mathrm{lin}}\) = HydrogenicNLin (0 selects Nelements - 1), \(R_1\) = HydrogenicR1 (0 selects 0.1 a.u.) and \(N_{\exp}\) = HydrogenicNExp (0 selects 10), the half-axis knots are

(15)\[r_i = i R_1, \qquad i = 0, \dots, N_{\mathrm{lin}},\]

followed by the exponentially graded knots

(16)\[r_{\mathrm{c}}\left(\frac{L}{r_{\mathrm{c}}}\right)^{k/N_{\exp}}, \qquad k = 1, \dots, N_{\exp} - 1, \qquad r_{\mathrm{c}} = N_{\mathrm{lin}} R_1 ,\]

so that each half axis carries \(N_{\mathrm{lin}}\) linear and \(N_{\exp}\) exponential elements and the axis has \(2(N_{\mathrm{lin}} + N_{\exp})\) elements; Nelements only enters through the default of HydrogenicNLin. \(r_{\mathrm{c}} < L\) is required; otherwise the run stops with a message. The outermost element has the width \(L\,[1 - (r_{\mathrm{c}}/L)^{1/N_{\exp}}]\).

HydrogenicHMax (alias HydrogenicMaxSpacing) caps the element width at \(h_{\max}\): from the first element \([r_j, r_{j+1}]\) wider than \(h_{\max}\), the rest of the half axis is replaced by

(17)\[\nu = \left\lceil \frac{L - r_j}{h_{\max}} \right\rceil\]

uniform elements. A positive value sets \(h_{\max}\); a negative value disables the cap; 0 (default) derives \(h_{\max} = \pi/(2k_{\max})\) from the field (Eq. (19)) when EnablePropagation = 1 and the field is non-zero, and applies no cap otherwise. The start-up line TDSEZHydrogenicKnots reports the element count, \(R_1\), the largest width (marked “capped” when the cap is active) and \(r_{\mathrm{c}}\).

Interface-aligned sequence

interface places knots at the material interfaces of heterostructures described by piecewise expressions. The breakpoints are read from comparisons of the form x < c, x <= c, x > c, x >= c (breakpoint \(c\)) and abs(x) < c or fabs(x) < c (breakpoints \(\pm c\)) in Potential and Mass, with \(c\) a numeric literal; comparisons on other operands are ignored. Breakpoints are taken from comparisons on x only, and the same positions are used on every axis that selects interface.

The Nelements elements are distributed over the layers between the breakpoints in proportion to the layer width (at least one per layer) and are uniform within each layer. Every interior breakpoint is a knot of multiplicity \(p\), so the basis is \(C^0\) there and can represent the kink of the BenDaniel-Duke wave function at an abrupt interface [BenDanielDuke1966] (continuous \(\psi\) and \(m^{-1}\psi'\), discontinuous \(\psi'\)). Each interface adds \(p - 1\) basis functions. Without breakpoints the sequence is uniform and a message is printed.

Field-resolution check

When EnablePropagation = 1 and the field is non-zero, TDSE-Z estimates the field scales once from the input and compares them with the mesh of every axis, for every knot sequence:

  • \(E_0\): the largest \(|E_a(t)|\) over the polarised axes, sampled at 20 001 points on \([0, T]\), \(T\) = FinalTime;

  • \(\omega\): the largest Omegax/y/z of the polarised axes; if all are zero, it is estimated from the zero crossings of the dominant field component (at least three crossings required);

  • \(I_p\): \(-\) TargetEigenvalue if negative, otherwise 0.5.

The highest return momentum follows from the classical cutoff law [Krause1992] [Corkum1993],

(18)\[U_p = \frac{E_0^2}{4\omega^2}, \qquad k_{\max} = \sqrt{2\,(3.17\,U_p + I_p)},\]

and the required element width is about four elements per de Broglie wavelength of the fastest returning electron,

(19)\[h \le \frac{\pi}{2k_{\max}} .\]

This applies to the axes coupled to the field (Polarization). Across the field the electron moves with the much smaller transverse momentum spread, and the element width may be larger by TransverseElementFactor (\(f\), default 2, at least 1),

(20)\[h_\perp \le f\,\frac{\pi}{2k_{\max}} ,\]

measured in High-harmonic generation. The start-up output prints \(E_0\), \(\omega\), \(U_p\), \(I_p\), \(k_{\max}\) and both widths, and for each axis (marked polarised or transverse) either the widest element (“resolved”) or a warning with the axis, the widest element and its position. The grid is not modified; only hydrogenic with HydrogenicHMax = 0 uses these widths as its per-axis caps. \(E_0\) and the zero-crossing estimate of \(\omega\) are taken from \([0, \mathrm{FinalTime}]\): a test run with a shortened FinalTime sees only the beginning of the pulse and may obtain a different width. The zero-crossing estimate is accurate to a few per cent for short ramped pulses; the criterion Eq. (19) has a margin of about a factor of two (see High-harmonic generation).

Convergence studies

The following results were measured with TDSE-Z and serve as guidance for choosing grids.

Coulomb potential: 3D hydrogen

Setup: \(V = -1/r\), degree 3, 8 Gauss points, hydrogenic with \(R_1 = 0.05\), \(N_{\mathrm{lin}} = 5\), \(N_{\exp} = 10\) (35 937 DOFs on \(\pm 10\)); exact ground-state energy \(-0.5\).

Box size and boundary condition. The box size dominates the error. With Neumann boundaries (Boundary Conditions) the wave function is not forced to zero at the wall, and the ground-state energy falls below the exact value when the box truncates the tail of the state, because the truncated tail carries positive local energy. Beyond 5 a.u. the 1s state holds 0.3 % of the probability.

The energies are printed to six significant digits; the \(n = 3\) levels lie 1.6–2.6·10-6 from the exact value.

Grading. Refining the inner region (5 elements of 0.05 a.u.) changes the ground-state energy by less than 10-6; the accuracy is limited by the outer, exponentially graded elements (13 instead of 10 exponential elements: error 3.2·10-6 → 7.8·10-7). Smaller inner elements at a fixed element count increase the error (\(R_1\) = 0.01–0.02: 8–18·10-6) because the outer elements become coarser. The outermost exponential element is 3.1 a.u. wide on \(\pm 10\) and 5 a.u. on \(\pm 20\), which is too coarse for ionised or excited electrons during propagation. HydrogenicHMax limits this width without changing the bound states noticeably (\(\pm 10\), HydrogenicHMax = 1: 68 921 DOFs, \(E_0 = -0.49999866\)).

Quadrature. The nucleus lies on a knot, where no Gauss-Legendre point falls. On the 8 elements that touch it, the 8-point rule integrates the \(1/r\) singularity with a relative error of 1.6·10-4; the ground-state energy changes by 7·10-7 from 8 to 10 points. Fewer points under-integrate the singularity and overestimate the attraction, which can cancel the discretisation error by accident (4 points: -0.500009, below the exact value; 6 points: -0.4999990). Convergence must therefore be judged in the number of points, not by the distance to -0.5. QuadratureRule = reduced behaves like a Gauss rule with fewer points (-0.4999976 with 8 points); lobatto places points on the knots, where \(1/r\) is infinite, and the run stops after assembly with a message. The assembly takes 0.24–0.39 s for 4 to 10 points; the eigensolve time does not depend on the rule.

High-harmonic generation

HHG requires resolution at both ends of the grid: far out, where the returning electron travels, and at the nucleus, where it recombines [Corkum1993] [Lewenstein1994].

Setup: 2D hydrogen-like atom (\(V = -0.5/r\), \(I_p = 0.5\)), 800 nm, \(10^{14}\) W/cm², flat-top pulse, box \([-65,65]\times[-40,40]\) with CAP, degree 3, Propagator = pade22. The error measure is the deviation of the integrated odd-harmonic yields of \(|\tilde A|^2\) from a reference grid (\(R_1 = 0.02\), HydrogenicHMax = 0.25, 179k DOFs), in decades, \(|\log_{10} I/I_{\mathrm{ref}}|\). The harmonic cutoff lies at H24.
