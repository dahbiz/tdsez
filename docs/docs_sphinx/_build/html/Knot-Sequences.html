Knot Sequences

B-spline knot vector generation supports uniform, symmetric exponential and tangent, logarithmic tangent, hydrogenic, and interface-aligned sequences. Any other name (including the removed placeholders adaptive and adaptive_wf) stops the run with a message.

Tangent map, mildly dense near origin

interface (alias interfaces)

C0 knots (multiplicity p) at every breakpoint of the Potential and Mass expressions; uniform elements within each layer, element count per layer proportional to its width. Required for spectral accuracy at abrupt BDD heterojunctions.

Breakpoints from x < c / abs(x) < c comparisons

hydrogenic

Per half-axis: NLin linear elements of size R1 up to r_cross = NLin*R1, then NExp exponentially growing elements up to Lmax; mirrored about the origin. For Coulombic problems

HydrogenicR1 (alias InnerSpacing, HydrogenicInnerSpacing), HydrogenicNLin (alias InnerElements, HydrogenicInnerElements), HydrogenicNExp (alias OuterElements, HydrogenicOuterElements), HydrogenicHMax (alias HydrogenicMaxSpacing; largest element width, uniform beyond; 0 = from the field when propagating, < 0 = off); per-axis lists

Per-Axis Assignment

Knot sequences are comma-separated per axis:

KnotSequence = "symexp, uniform, symtan"

X=symexp, Y=uniform, Z=symtan. Missing axes default to the first value.

Coulomb Potentials (hydrogenic sequence)

Measured on the 3D hydrogen atom, \(V = -1/r\), degree 3, 8 Gauss points, HydrogenicR1 = 0.05, HydrogenicNLin = 5, HydrogenicNExp = 10 (35 937 DOFs), exact ground state \(-0.5\).

Box size and boundaries dominate. With the default natural (Neumann) boundaries the wavefunction is not forced to zero at the box, and the energy minimum then drops below the exact value when the box cuts the tail of the state (the cut-off tail has positive local energy). The 1s tail beyond 5 au holds 0.3 % of the probability:

Use \(\pm 10\) au for the ground state, \(\pm 20\) for n = 2 (on \(\pm 10\) the n = 2 energies are 3-6e-3 too low), about \(\pm 35\) for n = 3. On \(\pm 20\) with 15 exponential elements (79 507 DOFs) 1s and the four n = 2 states are within 2e-6.

Grading. Refining the inner region (5 x 0.05 au) changes the ground state by less than 1e-6; the outer, exponentially graded elements limit the accuracy (13 instead of 10 exponential elements: error 3.2e-6 -> 7.8e-7). Smaller inner elements at a fixed element count make it worse (R1 = 0.01-0.02: 8-18e-6), because the outer elements coarsen. The exponential tail grows to elements of \(L_{max}(1 - r_{cross}/L_{max})^{1/N_{exp}}\) (3.1 au on \(\pm 10\), 5 au on \(\pm 20\)), too coarse for ionised or excited electrons during propagation. HydrogenicHMax caps the width: from the first element that would be wider, the rest of the half-axis is uniform with width \(\le\) HMax. It does not change bound states noticeably (\(\pm 10\), HMax = 1: 68 921 DOFs, E0 = -0.49999866). The knot line printed at start-up reports the largest width.

High-harmonic generation. HHG needs both ends of the grid: the returning electron far out and the recombination at the nucleus. Measured on a 2D hydrogen-like atom (\(V=-0.5/r\), \(I_p = 0.5\)), 800 nm, \(10^{14}\) W/cm², flat-top pulse, box \([-65,65]\times[-40,40]\) with CAP, degree 3, pade22. The outer width converges at about four elements per wavelength of the fastest returning electron, \(h \le \pi/(2k_{max})\) with \(k_{max} = \sqrt{2(3.17U_p + I_p)}\) (1.0 au here; 2.0 au, about \(\pi/k_{max}\), fails); the remaining 1.6 % is set by the nucleus spacing, whose error grows about as \(R_1^{1.5}\) - keep R1 \(\le\) 0.05 au. The acceleration and current spectra agree to 0.001-0.005 decades in every run, so their agreement does not detect an under-resolved grid; only refinement does.

With HydrogenicHMax = 0 (default) and EnablePropagation = 1 with a field, the cap is derived from the input: \(E_0\) is the largest field over \([0, \mathrm{FinalTime}]\), \(\omega\) from Omegax/y/z or the zero crossings of the field, \(I_p\) from TargetEigenvalue (< 0) or 0.5, and the derivation is printed. On the run above it gives 0.976 au and the converged spectrum (median 0.007, max 0.031 decades). A short test run (small FinalTime) samples only the start of the pulse and gets a wider cap; set HMax explicitly when that matters. Bound-state-only runs are not capped.

Resolution check (every knot sequence). When propagating with a field, TDSE-Z prints the required width \(\pi/(2k_{max})\) and, for every axis, either the widest element (resolved) or a warning naming the axis, the widest element and its position. Grids are not changed; only hydrogenic caps its elements. \(\omega\) is taken from Omegax/y/z when given, else estimated from the field’s zero crossings (a few per cent off for short ramped pulses; the rule has a factor-two margin: 1.0 au converged, 2.0 au failed).

Quadrature. The nucleus sits on a knot (an element corner), where Gauss points never fall. Gauss-Legendre integrates the corner singularity of \(1/r\) with a relative error of 1.6e-4 (8 points) on the 8 elements that touch it; the ground state moves by 7e-7 from 8 to 10 points. Fewer points under-integrate the singularity and overestimate the attraction, which can cancel the discretisation error by accident (4 points: -0.500009, below the exact value; 6 points: -0.4999990) - converge in the number of points, not toward -0.5. QuadratureRule = reduced behaves like Gauss with fewer points (-0.4999976 at 8); lobatto puts points on the knots, where \(1/r\) is infinite, and is stopped at assembly with a message. Assembly time is 0.24-0.39 s for 4-10 points and the eigensolve does not depend on the rule.

Basis. At equal DOFs (50 653) the smooth B-splines are about 100 times more accurate than the C0 element bases, which span the same space as each other and differ only in conditioning:
