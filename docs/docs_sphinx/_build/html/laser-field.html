Laser Field

Polarization, envelopes, CEP, and field expressions.

Polarization

Field Expression

The field E(t) is specified via muParser expressions. Two modes:

  • Scalar form: Laser = Amplitude*cos(Omega*t)*sin(pi*t/PulseDuration)^2 – single envelope for all axes

  • Per-axis form: LaserX = ..., LaserY = ..., LaserZ = ... – overrides scalar form when set
