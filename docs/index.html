TDSE-ⵣ is a high-performance framework for simulating the time-dependent Schrödinger equation in strong laser fields. Built for atomic, molecular, and heterostructure systems with attosecond resolution and MPI scalability.

Two-line input, HPC-grade output

Configure potentials, pulses, and observables through a concise parameter file.

examples/model.inp 
# Domain and basis
Dimension = 1
LMin = -120.0
LMax =  120.0
NSplines = 600
SplineDegree = 5

# 1D soft-Coulomb atom
Mass = 1.0
Potential = -1.0 / sqrt(x^2 + 1.0)

# 3-cycle 800 nm pulse
Ampx = 0.05
Omegax = 0.056954
LaserX = Ampx*cos(Omegax*t)*sin(pi*t/331.0)^2

# Time propagation
TimeStep = 0.05
FinalTime = 331.0
